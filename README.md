# پورٹل دسترس (Dastaras)
### پاکستان اور کشمیر کے لیے معلومات، تعلیم اور رابطوں کا معتبر مرکز

**دسترس** ایک جدید، تیز رفتار اور خالص اردو معلوماتی پورٹل ہے جو خاص طور پر پاکستان اور آزاد جموں و کشمیر کے عوام، طلبہ، قارئین اور محققین کے لیے تیار کیا گیا ہے۔

---

## 🌟 بنیادی خصوصیات (Core Features)

1. **۱۰۰٪ خالص اردو انٹرفیس مع جمیل نوری نستعلیق (Jameel Noori Nastaleeq):**
   - کوئی انگریزی مینو یا لیبل نہیں، تمام بٹن، نیویگیشن، ڈائریکٹری، اور الرٹس مستند و سلیس اردو میں ہیں۔
   - `dir="rtl"` اور `lang="ur"`۔
   - جمیل نوری نستعلیق فونٹ کے لیے خصوصی لائن ہائٹ (`2.2` سے `2.5`) تاکہ کشیدہ اور عمودی الفاظ کبھی نہ کٹیں۔

2. **خبریں، سائنس اور مضامین کا علمی مرکز (News & Knowledge Hub):**
   - کیٹیگریز: خبریں، سائنسی معلومات، انٹرنیٹ و ٹیکنالوجی، خصوصی مضامین۔
   - فیچرڈ تحریر، لائیو سرچ، کیٹیگری فلٹرز اور خلفشار سے پاک ریڈنگ پیج۔
   - واٹس ایپ اور فیس بک پر اردو میں شیئر کرنے کے براہ راست بٹنز۔

3. **پاکستان اور کشمیر اسمارٹ ڈائریکٹری (Smart Directory):**
   - خطوں کے لحاظ سے فلٹر: آزاد کشمیر، گلگت بلتستان، پنجاب، سندھ، خیبر پختونخوا، بلوچستان، اسلام آباد۔
   - شعبہ جات: تھانے، یونیورسٹیز، سرکاری دفاتر، ہسپتال و ایمرجنسی، تعلیمی بورڈز۔
   - فوری سرچ، ایک کلک پر براہ راست **"کال کریں"** (`tel:`) اور **"نمبر کاپی کریں"** (مع اردو ٹوسٹ: "نمبر کاپی ہو گیا")۔

4. **عوامی مضمون نویسی اور ایڈمن پینل (Public Submissions & Admin Panel):**
   - عوام الناس بغیر لاگ ان کے اپنا علمی مضمون، تجزیہ یا سائنسی تحریر ارسال کر سکتے ہیں۔
   - جمع ہونے پر فوری اردو تصدیق: *"آپ کا مضمون موصول ہو گیا ہے، ایڈمن کی منظوری کے بعد شائع کر دیا جائے گا۔"*
   - مکمل ایڈمن کنٹرول پینل (`/admin`): زیر التواء مضامین کا جائزہ، فوری "منظور کریں" (لائیو اشاعت) یا "مسترد کریں"، اور نئے رابطہ نمبرز و داخلے شامل کرنے کی سہولت۔

5. **پاکستانی اخبارات کا مرکز (Newspapers Hub):**
   - جنگ، ایکسپریس، نوائے وقت، دنیا، مشرق، اوصاف، ڈان، دی نیوز وغیرہ کے براہ راست آن لائن مطالعہ اور ای پیپرز لنکس۔

6. **جامعات اور خودکار داخلہ اشتہارات (Universities & Automated Admissions):**
   - آزاد کشمیر، گلگت بلتستان اور ملک بھر کی نمایاں جامعات کی فہرست مع سرکاری ویب لنکس۔
   - نیکسٹ جے ایس اے پی آئی روٹ (`/api/admissions/sync`) جو ورسل کرون (`vercel.json`) کے ذریعے آر ایس ایس فیڈز سے داخلوں کو خودکار اپ ڈیٹ کرتا ہے۔

## 🛠️ تکنیکی ڈھانچہ (Tech Stack)

- **فریم ورک:** Next.js 14 (App Router, React 18, TypeScript)
- **اسٹائلنگ:** Tailwind CSS (Custom Nastaleeq line-height & colors)
- **شبیہیں (Icons):** Lucide React
- **ڈیٹا بیس و تصدیق:** Supabase (PostgreSQL + RLS Policies) مع آف لائن کیشنگ فال بیک
- **کرون جابز:** Vercel Cron (`vercel.json`)

---

## 🗄️ سپابیس ڈیٹا بیس سیٹ اپ (Supabase SQL Setup)

1. [Supabase](https://supabase.com) پر نیا پروجیکٹ بنائیں۔
2. بائیں جانب **SQL Editor** میں جائیں اور `supabase/schema.sql` فائل کے تمام مشمولات پیسٹ کر کے **Run** پر کلک کریں۔
3. اس سے تمام ٹیبلز (`articles`, `directory_contacts`, `universities`, `admissions`, `newspapers`)، آر ایل ایس پالیسیز (RLS Policies) اور حقیقت پسندانہ اردو سیڈ ڈیٹا خودکار طور پر تیار ہو جائے گا۔
4. اپنے پروجیکٹ کے API کریڈینشلز `.env.local` میں شامل کریں:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
   ```

## 🚀 لوکل انسٹالیشن اور رن کرنے کا طریقہ

```bash
# انسٹالیشن
npm install

# لوکل ڈیولپمنٹ سرور
npm run dev

# پروڈکشن بلڈ (Testing Build)
npm run build
npm run start
```

براؤزر میں [http://localhost:3000](http://localhost:3000) کھولیں۔

## ☁️ ورسل پر تعیناتی (Deploying to Vercel)

1. کوڈ کو GitHub پر پش کریں۔
2. Vercel ڈیش بورڈ پر جائیں اور نیا پروجیکٹ امپورٹ کریں۔
3. Environment Variables میں `NEXT_PUBLIC_SUPABASE_URL` اور `NEXT_PUBLIC_SUPABASE_ANON_KEY` شامل کریں۔
4. **Deploy** پر کلک کریں۔ `vercel.json` کے تحت داخلہ فیڈ سنک کرون ہر ۱۲ گھنٹے بعد خودکار چلے گا۔
